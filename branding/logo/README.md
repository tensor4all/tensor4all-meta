Status: proposal, not yet adopted.

## Concept

The mark is a small tensor network drawn as a circuit: open legs, hollow nodes, and bonds with rounded corners.

- Its bonds on the left, middle and right mimic the letter t, numeral 4 and letter a in the name, and the copper color used for 4 is the same as for the 4 in the wordmark.
- Line art in ink and copper only, matching the tenferro and colmat logos.

At 16 px only the copper 4 is kept.

## Files

| File | Use |
| --- | --- |
| `svg/tensor4all-mark.svg` | Mark for light backgrounds, transparent |
| `svg/tensor4all-mark-dark.svg` | Mark for dark backgrounds, transparent |
| `svg/tensor4all-mark-auto.svg` | Mark that follows `prefers-color-scheme` |
| `svg/tensor4all-wordmark.svg` | Horizontal logo for light backgrounds, text outlined |
| `svg/tensor4all-wordmark-dark.svg` | Horizontal logo for dark backgrounds, text outlined |
| `svg/tensor4all-avatar.svg` | Square avatar on the site background, safe for circular crops |
| `svg/tensor4all-avatar-dark.svg` | Square avatar, dark |
| `svg/favicon.svg` | Favicon with heavier strokes, follows `prefers-color-scheme` |
| `svg/tensor4all-icon-small.svg` | Opaque small icon, source for the 32 and 48 px PNG favicons |
| `svg/tensor4all-icon-16.svg` | Opaque 16 px icon, the copper 4 only |
| `png/tensor4all-avatar-{512,1024}.png` | GitHub organization avatar, social cards |
| `png/favicon-{16,32,48}.png`, `png/apple-touch-icon.png` | Raster favicons for browsers that do not use SVG |

The node rings are hollow: the bonds are masked out under them, so the mark works on any background.

## Colors

The family palette, taken from the tensor4all.org site and shared with tenferro and colmat.

| Role | Light | Dark |
| --- | --- | --- |
| Ink: bonds, nodes, wordmark text | `#1d2126` | `#e6e8eb` |
| Copper: the 4 in the mark and the wordmark | `#a3521a` | `#f0a46b` |
| Avatar background | `#fbfaf7` | `#14171b` |

The wordmark is set in IBM Plex Sans SemiBold (SIL Open Font License 1.1) with tracking of -0.03 em and kerning, converted to outlines. All tensor4all logos use the same type.
