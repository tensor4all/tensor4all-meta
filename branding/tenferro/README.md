## Concept

The mark is a hex nut drawn as line art, with a tensor-product sign (a circled cross) as its hole.

- *ferro* is iron, and iron rusts: the name says tenferro is written in Rust. The nut is an iron part, and the copper-rust color carries the same idea.
- tenferro is a general tensor computation engine (einsum over any algebra, autodiff, linear algebra), not a tensor network library, so the mark uses the tensor product rather than a network diagram.
- A nut is a part you bolt into something larger, which fits a runtime that other libraries and languages build on through its C API.

The nut is in the ink color and the circled cross in copper. In the wordmark, **ferro** is in copper.

## Regenerating

The SVGs are generated by `tools/export_logo.py`. It needs `fontTools` and a copy of IBM Plex Sans Bold (`.ttf` or `.woff`).

```bash
python3 tools/export_logo.py path/to/IBMPlexSans-Bold.ttf svg
```

The PNGs are rendered from the SVGs with `rsvg-convert`:

```bash
rsvg-convert -h 240 svg/tenferro-wordmark.svg -o png/tenferro-wordmark-240h.png
rsvg-convert -h 240 svg/tenferro-wordmark-dark.svg -o png/tenferro-wordmark-dark-240h.png
for s in 512 1024; do rsvg-convert -w $s svg/tenferro-avatar.svg -o png/tenferro-avatar-$s.png; done
rsvg-convert -w 512 svg/tenferro-avatar-dark.svg -o png/tenferro-avatar-dark-512.png
rsvg-convert -w 16 svg/tenferro-icon-16.svg -o png/favicon-16.png
for s in 32 48; do rsvg-convert -w $s svg/tenferro-icon-small.svg -o png/favicon-$s.png; done
rsvg-convert -w 180 svg/tenferro-avatar.svg -o png/apple-touch-icon.png
```

Geometry (nut points, circle radius, stroke weights) and colors are set at the top of the script.
